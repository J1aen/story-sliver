# 匿名故事碎片墙 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **工作约定（必须遵守）**：每完成一个任务或修复，**必须同步更新本文件**——勾选对应步骤、更新任务状态（✅ 已完成 / 🔧 进行中 / ⚠ 待修）、记录提交号，并和代码放在同一个 commit 一起提交推送。

**Goal:** 实现一个可真实上线的匿名故事碎片墙：注册登录（可选匿名发布、管理员审核、点赞、隐藏、硬删除），部署到腾讯云学生机，`http://IP:8080` 直连可用。

**Architecture:** 前后端分离。后端 Spring Boot 3 + MyBatis + MySQL（现有 `fragment-story` 骨架扩展），提供 JWT 认证、角色权限（普通/管理员/站长）、碎片生命周期（待审核→已发布→已隐藏）与硬删除；前端 Vue3 + Vite + JavaScript 单页应用，Axios 调用 `/api`，打包后由 Spring Boot 单端口 8080 托管。

**Tech Stack:** Java 17、Spring Boot 3.3.5、MyBatis 3.0.4、MySQL 8、Lombok、jjwt 0.12.6、spring-security-crypto、JUnit5 + Mockito；Vue3、Vite、Vue Router 4、Axios、手写 CSS。

## Global Constraints

- 后端 JDK 17，Spring Boot `3.3.5`，MyBatis `3.0.4`，MySQL 8，Lombok（沿用现有 pom，仅新增 jjwt 与 spring-security-crypto）
- 密码一律 BCrypt 加密存储；认证用 JWT，`app.jwt.expire-days: 30`

- 统一响应 `Result{code,message,data}`，沿用现有 `com.storysliver.common`

- 工作区目录名含特殊连字符，命令行一律使用相对路径

## 代码注释规范（必须遵守）

后端所有 Java 代码（含测试类）、Mapper XML、SQL、配置文件都必须有**详细中文注释**，遵循三条原则：

1. **这是什么**：类 / 接口 / 字段说明它对应什么、属于哪一层
2. **干什么用的**：方法说明它的职责、参数含义、返回值、可能抛出的异常
3. **为什么这么写**：关键语句说明设计原因，例如「为什么用线程安全集合」「为什么先校验再写库」「为什么硬删除前先查询」

规范示例（以下所有后端代码块均按此风格注释）：

```java
/**
 * 用户实体：对应 user 表。
 * 干什么用：承载注册/登录用户的全部字段，在 Mapper、Service、Controller 之间传递。
 * 为什么这么设计：字段与表结构一一对应，驼峰命名由 MyBatis map-underscore-to-camel-case 自动映射。
 */
@Data

    /** 角色常量：0 普通用户（默认）、1 管理员、2 站长。用 int 存库简单、可扩展 */
    public static final int ROLE_USER = 0, ROLE_ADMIN = 1, ROLE_OWNER = 2;
    /** 用户状态：0 正常、1 封禁（预留） */
    public static final int STATUS_NORMAL = 0, STATUS_BANNED = 1;
```

```java
/**
 * 注册业务实现。
 * 干什么用：完成注册全流程（验证码校验 → IP 限流 → 参数校验 → 唯一性校验 → 角色判定 → 落库 → 签发 token）。
 * 为什么这么设计：把「校验」集中在 Service 层，Controller 保持轻薄，业务规则可独立单测。
 */
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    /**
     * 注册用户。
     * @param request 注册表单（用户名/昵称/密码/验证码/管理员选项）
     * @param ip 客户端 IP，用于注册限流
     * @return JWT token（注册成功即自动登录）
     * @throws BusinessException 验证码错误 / 限流 / 用户名重复 / 管理员密码错误等
     */
    @Override
    public String register(RegisterRequest request, String ip) {
        // 先校验验证码：一次性使用（verify 内部 remove），防止脚本重放
        if (!captchaService.verify(request.getCaptchaKey(), request.getCaptchaAnswer())) {
            throw new BusinessException(ResultCode.CAPTCHA_ERROR);
        }
        // 再限流：验证码挡脚本，IP 限流兜底，双保险
        if (!registerRateLimiter.isAllowed(ip)) {
            throw new BusinessException(ResultCode.REGISTER_TOO_FREQUENT);
        }
        // 密码强度是最基本的防线：至少 6 位
        if (request.getPassword() == null || request.getPassword().length() < 6) {
            throw new BusinessException(ResultCode.PASSWORD_TOO_WEAK);
        }
        // 用户名唯一是登录体系的前提，冲突直接拒绝
        if (userMapper.selectByUsername(request.getUsername()) != null) {
            throw new BusinessException(ResultCode.USERNAME_TAKEN);
        }
        // 管理员注册需要特殊密码，密码只存 BCrypt 哈希，绝不存明文
        int role = User.ROLE_USER;
        if (Boolean.TRUE.equals(request.getIsAdmin())) {
            SystemConfig cfg = systemConfigMapper.selectByKey(SystemConfig.KEY_ADMIN_REGISTER_CODE);
            if (cfg == null || request.getAdminCode() == null
                    || !passwordEncoder.matches(request.getAdminCode(), cfg.getConfigValue())) {
                throw new BusinessException(ResultCode.ADMIN_CODE_WRONG);
            }
            // 第一个用特殊密码注册的管理员自动成为站长；之后都是普通管理员
            role = userMapper.countAll() == 0 ? User.ROLE_OWNER : User.ROLE_ADMIN;
        }
        // 密码加密后落库，任何人（包括管理员）都看不到明文
        User user = new User();
        user.setUsername(request.getUsername().trim());
        user.setNickname(request.getNickname().trim());
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setRole(role);
        user.setStatus(User.STATUS_NORMAL);
        userMapper.insert(user);
        // 注册成功直接返回 token，省去「注册后再登录」一步，提升体验
        return jwtUtil.generateToken(user.getId(), user.getRole());
    }
}
```

### Service 写法（接口 + impl）

```java
public interface FragmentService {
    /**发布碎片（进入待审核）*/
    void submit(Long userId, String content, boolean anonymous);
}

@Service
public class FragmentServiceImpl implements FragmentService {
    @Autowired
    private StoryFragmentMapper fragmentMapper;

    /**发布碎片：先校验内容长度，再校验 5 分钟限频，最后落库*/
    @Override
    public void submit(Long userId, String content, boolean anonymous) {
        //内容先 trim 再判空，防止纯空格提交
        String text = content == null ? "" : content.trim();
        if (text.isEmpty() || text.length() > 1000) {
            throw new BusinessException(ResultCode.FRAGMENT_TOO_LONG);
        }
        //发布频率限制：每个用户 5 分钟 1 条
        if (!fragmentRateLimiter.tryAcquire(userId)) {
            throw new BusinessException(ResultCode.FRAGMENT_TOO_FREQUENT);
        }
        StoryFragment fragment = new StoryFragment();
        fragment.setUserId(userId);
        fragment.setContent(text);
        fragment.setIsAnonymous(anonymous ? 1 : 0);
        fragmentMapper.insert(fragment);
    }
}
```

```sql
-- ============================================================
-- 匿名故事碎片墙数据库初始化脚本
-- 干什么用：一次性创建全部表结构与索引（开发期直接重建，上线后勿重复执行）
-- 为什么用 utf8mb4：完整支持中文与 emoji，避免生僻字/表情存不进去
-- ============================================================
CREATE DATABASE IF NOT EXISTS story_sliver DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE story_sliver;

DROP TABLE IF EXISTS fragment_like;
DROP TABLE IF EXISTS story_fragment;
DROP TABLE IF EXISTS system_config;
DROP TABLE IF EXISTS `user`;

CREATE TABLE `user` (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键',
  username VARCHAR(32) NOT NULL COMMENT '登录用户名',
  nickname VARCHAR(32) NOT NULL COMMENT '展示昵称',
  password VARCHAR(100) NOT NULL COMMENT 'BCrypt 哈希',
  email VARCHAR(100) DEFAULT NULL COMMENT '预留邮箱',
  role TINYINT NOT NULL DEFAULT 0 COMMENT '0普通 1管理员 2站长',
  status TINYINT NOT NULL DEFAULT 0 COMMENT '0正常 1封禁',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户';

CREATE TABLE story_fragment (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键',
  user_id BIGINT UNSIGNED NOT NULL COMMENT '真实发布者',
  content TEXT NOT NULL COMMENT '内容(<=1000字)',
  like_count INT NOT NULL DEFAULT 0 COMMENT '点赞数',
  is_anonymous TINYINT NOT NULL DEFAULT 0 COMMENT '0显示昵称 1匿名',
  status TINYINT NOT NULL DEFAULT 0 COMMENT '0待审核 1已发布 2已隐藏',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  KEY idx_user (user_id),
  KEY idx_status_created (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='故事碎片';

CREATE TABLE fragment_like (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  fragment_id BIGINT UNSIGNED NOT NULL,
  user_id BIGINT UNSIGNED NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
```

```java
/**
 * JWT 配置属性：读取 application.yml 的 app.jwt.*。
 * 干什么用：把签名密钥和有效期从代码里抽出来，部署时只改配置、不改代码。
 */
@Data
@Component
@ConfigurationProperties(prefix = "app.jwt")
public class JwtProperties {
    /** 签名密钥：HS256 要求至少 32 字节，生产环境必须改成随机长字符串 */
    private String secret;
    /** token 有效期（天），MVP 定为 30 天，到期后需重新登录 */
    private int expireDays;
}

/**
 * JWT 工具类：负责签发和解析 token。
 * 干什么用：登录/注册成功后签发 token；每次请求由 AuthInterceptor 调用 parse 校验身份。
 * 为什么这么设计：JWT 无状态，服务重启不失效，也无需 Redis 存储会话。
 */
@Component
@RequiredArgsConstructor
public class JwtUtil {
    private final JwtProperties properties;

    /** 由配置密钥构造 HS256 签名密钥：密钥长度不够会抛异常，所以配置里必须 >=32 字节 */
    private SecretKey key() {
        return Keys.hmacShaKeyFor(properties.getSecret().getBytes(StandardCharsets.UTF_8));
    }

    /**
     * 签发 token。
     * @param userId 用户主键，放进 subject，便于随时取回
     * @param role 角色，放进自定义 claim，拦截器做权限判断时不用再查库
     */
    public String generateToken(Long userId, Integer role) {
        Instant now = Instant.now();
        return Jwts.builder()
                .subject(String.valueOf(userId))
                .claim("role", role)
                .issuedAt(Date.from(now))
                .expiration(Date.from(now.plus(properties.getExpireDays(), ChronoUnit.DAYS)))
                .signWith(key())
                .compact();
    }

    /** 解析并校验签名；token 无效或过期会抛 JwtException，由调用方捕获 */
    public Claims parse(String token) {
        return Jwts.parser().verifyWith(key()).build().parseSignedClaims(token).getPayload();
    }
}

/**
 * 当前登录用户上下文。
 * 干什么用：拦截器解析 token 后把 userId/role 放进 ThreadLocal，Controller/Service 直接读取。
 * 为什么这么设计：避免每个方法都手动传用户参数；请求结束必须 clear，防止线程池复用导致串号。
 */
public final class UserContext {
    private static final ThreadLocal<Long> USER_ID = new ThreadLocal<>();
    private static final ThreadLocal<Integer> ROLE = new ThreadLocal<>();
    /** 请求开始时写入当前用户 */
    public static void set(Long userId, Integer role) { USER_ID.set(userId); ROLE.set(role); }
    /** 读取当前用户 id；未登录时为 null */
    public static Long getUserId() { return USER_ID.get(); }
    /** 读取当前用户角色 */
    public static Integer getRole() { return ROLE.get(); }
    /** 请求结束时清理，防止 ThreadLocal 内存泄漏/串号 */
    public static void clear() { USER_ID.remove(); ROLE.remove(); }
}

/**
 * 角色校验注解：标注在 Controller 方法上，由 AuthInterceptor 读取执行。
 * 例子：@RequireRole(User.ROLE_OWNER) 表示只有站长可访问。
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RequireRole { int[] value(); }

/**
 * 认证拦截器：处理所有 /api/** 请求（公开接口在 WebConfig 排除）。
 * 干什么用：解析并校验 JWT → 写入 UserContext → 检查方法上的 @RequireRole。
 */
@Component
@RequiredArgsConstructor
public class AuthInterceptor implements HandlerInterceptor {
    private final JwtUtil jwtUtil;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler)
            throws Exception {
        // 统一约定：token 放在 Authorization: Bearer <token> 头里
        String auth = request.getHeader("Authorization");
        String token = (auth != null && auth.startsWith("Bearer ")) ? auth.substring(7) : null;
        Claims claims;
        try {
            // 解析失败（过期/篡改/缺失）统一按未登录处理，不区分细节，避免信息泄露
            claims = token == null ? null : jwtUtil.parse(token);
        } catch (Exception e) {
            claims = null;
        }
        if (claims == null) {
            writeUnauthorized(response);
            return false;
        }
        // 从 token 里取身份：subject 是 userId，role 是自定义 claim
        Long userId = Long.valueOf(claims.getSubject());
        Integer role = claims.get("role", Integer.class);
        UserContext.set(userId, role);

        // 方法上标了 @RequireRole 才做角色校验；没标表示登录即可
        if (handler instanceof HandlerMethod hm) {
            RequireRole requireRole = hm.getMethodAnnotation(RequireRole.class);
            if (requireRole != null) {
                boolean allowed = Arrays.stream(requireRole.value()).anyMatch(r -> r == role);
                if (!allowed) {
                    UserContext.clear();
                    response.setStatus(403);
                    response.setContentType(MediaType.APPLICATION_JSON_VALUE);
                    response.setCharacterEncoding(StandardCharsets.UTF_8.name());
                    response.getWriter().write(objectMapper().writeValueAsString(Result.error(ResultCode.FORBIDDEN)));
                    return false;
                }
            }
        }
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) {
        UserContext.clear();
    }

    /** 返回统一的 401 JSON，前端拦截到 401 自动跳登录页 */
    private void writeUnauthorized(HttpServletResponse response) throws Exception {
        response.setStatus(401);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        response.getWriter().write(objectMapper().writeValueAsString(Result.error(ResultCode.UNAUTHORIZED, "请先登录")));
    }

    private ObjectMapper objectMapper() { return new ObjectMapper(); }
}
```

```java
/**
 * 验证码响应体：返回给前端。
 * 干什么用：前端用 captchaKey 连同用户输入的答案一起提交注册，图片以 base64 直接显示。
 */
@Data
@AllArgsConstructor
public class CaptchaResponse {
    /** 本次验证码的会话标识：verify 时凭它取正确答案，用完即删（一次性） */
    private String captchaKey;
    /** 验证码图片的 base64（data:image/png;base64,...），前端 img 直接展示 */
    private String imageBase64;
}

/**
 * 算术验证码服务：防止注册被脚本批量刷。
 * 干什么用：生成「a + b = ?」图片和答案；校验答案是否正确（一次性）。
 * 为什么用算术题而不是字符验证码：纯 Java 生成、无第三方依赖，对真人几乎零门槛，对脚本有一定拦截效果。
 */
@Service
public class CaptchaService {
    /** key → 正确答案。用 ConcurrentHashMap：验证码接口并发高，保证线程安全 */
    private final Map<String, String> answers = new ConcurrentHashMap<>();

    /** 生成一道随机加法题：答案范围 2-18，简单到真人一眼能答 */
    public CaptchaResponse generate() {
        int a = ThreadLocalRandom.current().nextInt(1, 10);
        int b = ThreadLocalRandom.current().nextInt(1, 10);
        String key = UUID.randomUUID().toString();
        answers.put(key, String.valueOf(a + b));
        return new CaptchaResponse(key, renderImage(a + " + " + b + " = ?"));
    }

    /**
     * 校验答案。
     * 为什么 remove：取走即删除，保证「一次性」，防止脚本拿同一 key 反复试答案。
     */
    public boolean verify(String key, String answer) {
        String expected = answers.remove(key);
        return expected != null && expected.equals(answer == null ? "" : answer.trim());
    }

    /** 用 AWT 画一张米白底的算式图片；无需外部字体/图片资源，纯代码生成 */
    private String renderImage(String text) {
        try {
            BufferedImage image = new BufferedImage(140, 44, BufferedImage.TYPE_INT_RGB);
            Graphics2D g = image.createGraphics();
            g.setColor(new Color(247, 243, 234));
            g.fillRect(0, 0, 140, 44);
            g.setColor(new Color(74, 66, 56));
            g.setFont(new Font(Font.SANS_SERIF, Font.BOLD, 20));
            g.drawString(text, 12, 30);
            // 画几条干扰线：增加机器识别难度，但不影响真人阅读
            g.setColor(new Color(200, 180, 150));
            for (int i = 0; i < 6; i++) {
                g.drawLine(0, i * 8, 140, i * 8 + 5);
            }
            g.dispose();
            ByteArrayOutputStream out = new ByteArrayOutputStream();
            ImageIO.write(image, "png", out);
            // 转 base64 内嵌给前端，省一次图片请求
            return "data:image/png;base64," + Base64.getEncoder().encodeToString(out.toByteArray());
        } catch (IOException e) {
            throw new IllegalStateException("验证码生成失败", e);
        }
    }
}
```

```java
 * 干什么用：把 PasswordEncoder 声明为 Spring Bean，各处（注册、登录、管理配置）统一注入同一个实例。
 * 为什么用 BCrypt：自带盐值、慢哈希，是目前最常用的密码安全存储方案。
 */
@Configuration
public class BeanConfig {
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}

/**
 * 注册 IP 限流器：防批量注册脚本。
 * 干什么用：同一 IP 1 小时内最多 5 个、24 小时内最多 10 个注册。
 * 为什么放宽到 5/10：防止把同一 WiFi 下的真实小团体误伤（验证码才是主防线，这里只是兜底）。
 * 为什么用内存实现：单实例部署够用、零依赖；等以后多实例再换 Redis。
 */
@Service
public class RegisterRateLimiter {
    /** ip → 该 IP 的注册时间戳队列。ConcurrentHashMap + 对队列加锁，保证并发下计数准确 */
    private final Map<String, Deque<Long>> hits = new ConcurrentHashMap<>();
    private static final long HOUR_MS = 3_600_000L;
    private static final long DAY_MS = 86_400_000L;

    /** 尝试放行一次注册；超限返回 false。过期记录在检查时顺带清理，避免内存无限增长 */
    public boolean isAllowed(String ip) {
        long now = System.currentTimeMillis();
        Deque<Long> q = hits.computeIfAbsent(ip, k -> new ArrayDeque<>());
        synchronized (q) {
            // 先清掉 24 小时前的旧记录
            while (!q.isEmpty() && now - q.peekFirst() > DAY_MS) q.pollFirst();
            long hourCount = 0;
            for (Long t : q) if (now - t <= HOUR_MS) hourCount++;
            // 任一维度超限就拒绝；没超限就记录本次时间
            if (hourCount >= 5 || q.size() >= 10) return false;
            q.addLast(now);
            return true;
        }
    }
}

/**
 * 用户服务实现：注册/登录的核心业务逻辑。
 * 校验顺序为什么固定：验证码 → IP 限流 → 密码强度 → 用户名唯一 → 管理员密码，越廉价的校验越靠前，尽早拦截无效请求。
 */
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;
    private final SystemConfigMapper systemConfigMapper;
    private final CaptchaService captchaService;
    private final RegisterRateLimiter registerRateLimiter;
    private final PasswordEncoder passwordEncoder;
    private final JwtUtil jwtUtil;

    /**
     * 注册用户。
     * @param request 注册表单
     * @param ip 客户端 IP，用于注册限流
     * @return JWT token（注册成功即自动登录）
     * @throws BusinessException 验证码错误 / 限流 / 密码过弱 / 用户名重复 / 管理员密码错误
     */
    @Override
    public String register(RegisterRequest request, String ip) {
        // 先校验验证码：一次性（verify 内部 remove），防止脚本重放
        if (!captchaService.verify(request.getCaptchaKey(), request.getCaptchaAnswer())) {
            throw new BusinessException(ResultCode.CAPTCHA_ERROR);
        }
        // 再限流：验证码挡脚本、IP 限流兜底，双保险
        if (!registerRateLimiter.isAllowed(ip)) {
            throw new BusinessException(ResultCode.REGISTER_TOO_FREQUENT);
        }
        // 密码最短 6 位是最基本的强度底线
        if (request.getPassword() == null || request.getPassword().length() < 6) {
            throw new BusinessException(ResultCode.PASSWORD_TOO_WEAK);
        }
        // 用户名唯一是登录体系的前提，冲突直接拒绝
        if (userMapper.selectByUsername(request.getUsername()) != null) {
            throw new BusinessException(ResultCode.USERNAME_TAKEN);
        }

        int role = User.ROLE_USER;
        // 管理员注册：必须提供站长才知道的特殊密码；密码以 BCrypt 哈希存库
        if (Boolean.TRUE.equals(request.getIsAdmin())) {
            SystemConfig cfg = systemConfigMapper.selectByKey(SystemConfig.KEY_ADMIN_REGISTER_CODE);
            if (cfg == null || request.getAdminCode() == null
                    || !passwordEncoder.matches(request.getAdminCode(), cfg.getConfigValue())) {
                throw new BusinessException(ResultCode.ADMIN_CODE_WRONG);
            }
            // 第一个用特殊密码注册的管理员自动成为站长，之后都是普通管理员（防止人人都是站长）
            role = userMapper.countAll() == 0 ? User.ROLE_OWNER : User.ROLE_ADMIN;
        }

        // 密码加密后落库：任何人都看不到明文，包括管理员
        User user = new User();
        user.setUsername(request.getUsername().trim());
        user.setNickname(request.getNickname().trim());
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        user.setRole(role);
        user.setStatus(User.STATUS_NORMAL);
        userMapper.insert(user);
        // 注册成功直接返回 token：省去「注册后再登录」一步
        return jwtUtil.generateToken(user.getId(), user.getRole());
    }

    /**
     * 登录：按用户名查用户，BCrypt 比对密码。
     * 为什么用户名不存在和密码错误返回同一错误：不暴露「该用户是否存在」，防账号枚举。
     */
    @Override
    public String login(String username, String password) {
        User user = userMapper.selectByUsername(username);
        if (user == null || !passwordEncoder.matches(password, user.getPassword())) {
            throw new BusinessException(ResultCode.LOGIN_FAILED);
        }
        return jwtUtil.generateToken(user.getId(), user.getRole());
    }

    /** 查询当前用户信息：前端登录后拉取昵称、角色用于展示与路由守卫 */
    @Override
    public User me(Long userId) {
        return userMapper.selectById(userId);
    }
}
```

```java
 * 认证接口：验证码 / 注册 / 登录。
 * 这三个接口在 WebConfig 中被认证拦截器排除（公开访问）。

@RestController
@RequestMapping("/api/auth")
public class AuthController {
    @Autowired
    private UserService userService;//注册/登录业务
    @Autowired
    private CaptchaService captchaService;//验证码

    /** 获取注册用算术验证码 */
    @GetMapping("/captcha")
    public Result captcha() {
        return Result.success(captchaService.generate());
    }

    /** 注册：需要客户端 IP 用于限流，所以额外注入 HttpServletRequest */
    @PostMapping("/register")
    public Result register(@Valid @RequestBody RegisterRequest request, HttpServletRequest http) {
        String ip = clientIp(http);
        return Result.success(Map.of("token", userService.register(request, ip)));
    }

    /** 登录：用户名 + 密码，返回 token */
    @PostMapping("/login")
    public Result login(@Valid @RequestBody LoginRequest request) {
        return Result.success(Map.of("token", userService.login(request.getUsername(), request.getPassword())));
    }

    /**
     * 获取真实客户端 IP。
     * 为什么优先取 X-Forwarded-For：生产环境前面有 Nginx/负载均衡时，getRemoteAddr 拿到的是代理 IP；
     * 取第一个值是因为代理链里第一个才是真实客户端（防止伪造要由代理覆盖该头，部署章节有说明）。
     */
    private String clientIp(HttpServletRequest request) {
        String xff = request.getHeader("X-Forwarded-For");
        if (xff != null && !xff.isBlank()) return xff.split(",")[0].trim();
        return request.getRemoteAddr();
    }
}
```

```java
/**
 * 发布频率限流器：每个登录用户 5 分钟只能发 1 条。
 * 为什么按用户而不是按 IP：发布必须登录，按用户精准且不误伤同网络下的其他人。
 * 为什么用内存：单实例部署够用；将来多实例再换 Redis。
 */
@Service
public class FragmentRateLimiter {
    /** userId → 上次发布时间戳。ConcurrentHashMap 保证并发安全 */
    private final Map<Long, Long> lastSubmit = new ConcurrentHashMap<>();
    private static final long INTERVAL_MS = 5 * 60_000L;

    /** 尝试获取一次发布额度；间隔不足 5 分钟返回 false */
    public boolean tryAcquire(Long userId) {
        long now = System.currentTimeMillis();
        // putIfAbsent：第一次发布直接放行并记录时间
        Long prev = lastSubmit.putIfAbsent(userId, now);
        if (prev == null) return true;
        if (now - prev < INTERVAL_MS) return false;
        // 间隔已过，更新时间戳并放行
        lastSubmit.put(userId, now);
        return true;
    }
}
```

```java
/**
 * 碎片业务实现：发布、列表、我的碎片、点赞/取消、隐藏/取消隐藏、作者删除。
 * 为什么所有「操作自己的碎片」都先查询再校验：确保只能操作自己的、且状态合法的碎片，防止越权。
 */
@Service
public class FragmentServiceImpl implements FragmentService {
    @Autowired
    private StoryFragmentMapper fragmentMapper;//碎片表操作
    @Autowired
    private FragmentLikeMapper likeMapper;//点赞表操作
    @Autowired
    private UserMapper userMapper;//查昵称拼 authorName
    @Autowired
    private FragmentRateLimiter fragmentRateLimiter;//发布限频（5 分钟/条）

    /**
     * 发布碎片：进入「待审核」状态，不会立刻上墙。
     * 先校验内容再限频：内容非法（空/超长）的请求不占用发布额度。
     */
    @Override
    public StoryFragment submit(Long userId, String content, boolean anonymous) {
        String text = content == null ? "" : content.trim();
        if (text.isEmpty() || text.length() > 1000) {
            throw new BusinessException(ResultCode.FRAGMENT_TOO_LONG);
        }
        if (!rateLimiter.tryAcquire(userId)) {
            throw new BusinessException(ResultCode.FRAGMENT_TOO_FREQUENT);
        }
        StoryFragment f = new StoryFragment();
        f.setUserId(userId);
        f.setContent(text);
        f.setLikeCount(0);
        f.setIsAnonymous(anonymous ? 1 : 0);
        f.setStatus(StoryFragment.STATUS_PENDING);
        fragmentMapper.insert(f);
        return f;
    }

    /**
     * 首页分页列表：只返回「已发布」。
     * currentUserId 为 null 表示游客，不查点赞状态（likedByMe=false）。
     */
    @Override
    public PageBean list(int pageNum, int pageSize, Long currentUserId) {
        // PageHelper：查询前调用 startPage，它会给下一条查询自动加 LIMIT 分页
        PageHelper.startPage(pageNum, pageSize);
        // 只查已发布（status=1），分页参数由 PageHelper 注入
        List<StoryFragment> fragments = fragmentMapper.selectPublishedPage();
        // PageHelper 把结果包装成 Page：getTotal() 是总数，getResult() 是本页数据
        Page<StoryFragment> page = (Page<StoryFragment>) fragments;
        // 一次查出当前用户赞过的所有碎片 id，避免逐条查询 N+1 问题
        List<Long> likedIds = currentUserId == null ? List.of() : likeMapper.selectLikedFragmentIds(currentUserId);
        List<FragmentVO> vos = page.getResult().stream()
                .map(f -> toVO(f, likedIds.contains(f.getId())))
                .toList();
        return new PageBean(page.getTotal(), vos);
    }

    /** 我的碎片：返回自己的全部状态（待审核/已发布/已隐藏，含匿名的） */
    @Override
    public List<FragmentVO> my(Long userId) {
        return fragmentMapper.selectByUser(userId).stream()
                .map(f -> toVO(f, false))
                .toList();
    }

    /** 点赞：只能赞「已发布」的碎片；重复点赞由数据库唯一约束兜底，这里先友好拦截 */
    @Override
    public void like(Long userId, Long fragmentId) {
        requirePublished(fragmentId);
        if (likeMapper.exists(fragmentId, userId)) {
            throw new BusinessException(ResultCode.ALREADY_LIKED);
        }
        FragmentLike like = new FragmentLike();
        like.setFragmentId(fragmentId);
        like.setUserId(userId);
        likeMapper.insert(like);
        fragmentMapper.increaseLikeCount(fragmentId);
    }

    /** 取消点赞：先确认赞过，再删记录并把计数减回去 */
    @Override
    public void unlike(Long userId, Long fragmentId) {
        requirePublished(fragmentId);
        if (!likeMapper.exists(fragmentId, userId)) {
            throw new BusinessException(ResultCode.NOT_LIKED);
        }
        likeMapper.deleteByFragmentAndUser(fragmentId, userId);
        fragmentMapper.decreaseLikeCount(fragmentId);
    }

    /** 隐藏：只有作者能操作，且只允许隐藏「已发布」的碎片 */
    @Override
    public void hide(Long userId, Long fragmentId) {
        StoryFragment f = requireOwned(userId, fragmentId);
        if (f.getStatus() != StoryFragment.STATUS_PUBLISHED) {
            throw new BusinessException(ResultCode.FRAGMENT_NOT_PUBLISHED);
        }
        fragmentMapper.updateStatus(fragmentId, StoryFragment.STATUS_HIDDEN);
    }

    /** 取消隐藏：只有作者能操作，且只允许恢复「已隐藏」的碎片 */
    @Override
    public void unhide(Long userId, Long fragmentId) {
        StoryFragment f = requireOwned(userId, fragmentId);
        if (f.getStatus() != StoryFragment.STATUS_HIDDEN) {
            throw new BusinessException(ResultCode.FRAGMENT_NOT_PUBLISHED);
        }
        fragmentMapper.updateStatus(fragmentId, StoryFragment.STATUS_PUBLISHED);
    }

    /** 作者硬删除：删行并清掉该碎片全部点赞（同一事务，防止留下孤儿点赞记录） */
    @Override
    public void deleteByAuthor(Long userId, Long fragmentId) {
        requireOwned(userId, fragmentId);
        fragmentMapper.deleteById(fragmentId);
        likeMapper.deleteByFragmentAndUser(fragmentId, null);
    }

    /** 实体转 VO：匿名时显示「匿名用户」，实名时查一次用户表拿昵称 */
    @Override
    public FragmentVO toVO(StoryFragment f, boolean likedByMe) {
        FragmentVO vo = new FragmentVO();
        vo.setId(f.getId());
        vo.setContent(f.getContent());
        vo.setLikeCount(f.getLikeCount());
        vo.setIsAnonymous(f.getIsAnonymous());
        vo.setStatus(f.getStatus());
        vo.setLikedByMe(likedByMe);
        vo.setCreatedAt(f.getCreatedAt() == null ? "" : f.getCreatedAt().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")));
        // 匿名对外统一展示「匿名用户」，但数据库仍记录 user_id 供管理员追溯
        if (f.getIsAnonymous() == 1) {
            vo.setAuthorName("匿名用户");
        } else {
            User author = userMapper.selectById(f.getUserId());
            vo.setAuthorName(author == null ? "未知用户" : author.getNickname());
        }
        return vo;
    }

    /** 校验碎片存在且已发布：点赞/取消点赞的前置条件 */
    private void requirePublished(Long fragmentId) {
        StoryFragment f = fragmentMapper.selectById(fragmentId);
        if (f == null || f.getStatus() != StoryFragment.STATUS_PUBLISHED) {
            throw new BusinessException(ResultCode.FRAGMENT_NOT_PUBLISHED);
        }
    }

    /** 校验碎片存在且属于当前用户：隐藏/取消隐藏/删除的前置条件 */
    private StoryFragment requireOwned(Long userId, Long fragmentId) {
        StoryFragment f = fragmentMapper.selectById(fragmentId);
        if (f == null || !f.getUserId().equals(userId)) {
            throw new BusinessException(ResultCode.NOT_AUTHOR);
        }
        return f;
    }
}
```

```java
     * 为什么这里手动解析 token：该路径被拦截器排除（公开），但登录用户应看到「已赞」状态，所以做成「可选登录」。

        fragmentService.like(UserContext.getUserId(), id);
        return Result.success();
    }

    /** 取消点赞 */
    @DeleteMapping("/{id}/like")
    public Result unlike(@PathVariable Long id) {
        fragmentService.unlike(UserContext.getUserId(), id);
        return Result.success();
    }

    /** 隐藏（仅作者，仅已发布） */
    @PutMapping("/{id}/hide")
    public Result hide(@PathVariable Long id) {
        fragmentService.hide(UserContext.getUserId(), id);
        return Result.success();
    }

    /** 取消隐藏（仅作者，仅已隐藏） */
    @PutMapping("/{id}/unhide")
    public Result unhide(@PathVariable Long id) {
        fragmentService.unhide(UserContext.getUserId(), id);
        return Result.success();
    }

    /** 作者硬删除（前端弹窗确认） */
    @DeleteMapping("/{id}")
    public Result delete(@PathVariable Long id) {
        fragmentService.deleteByAuthor(UserContext.getUserId(), id);
        return Result.success();
    }

    /** 可选登录解析：token 合法就返回 userId，否则返回 null（游客），解析失败静默忽略 */
    private Long optionalUserId(HttpServletRequest http) {
        String auth = http.getHeader("Authorization");
        if (auth == null || !auth.startsWith("Bearer ")) return null;
        try {
            return Long.valueOf(jwtUtil.parse(auth.substring(7)).getSubject());
        } catch (Exception e) {
            return null;
        }
    }
```

```java
/**
 * 管理服务接口：审核、删除、用户管理、配置管理。
 * 为什么权限判断放在 Service 里：Controller 的 @RequireRole 只挡路由，Service 再做一次校验是纵深防御。
 */
public interface AdminService {
    /** 管理列表（按状态筛选：0 待审核 / 1 已发布；null 全部），匿名也显示真实昵称 */
    PageBean manageList(Integer status, int pageNum, int pageSize);
    /** 审核通过：只允许把「待审核」置为「已发布」 */
    void approve(Long fragmentId);
    /** 硬删除：审核不通过 / 删除违规碎片共用 */
    void deleteFragment(Long fragmentId);
    /** 用户分页列表（仅站长） */
    PageBean users(int pageNum, int pageSize);
    /** 指定/撤销管理员（仅站长；不能修改站长本人） */
    void updateRole(Integer operatorRole, Long targetUserId, Integer role);
    /** 修改管理员注册特殊密码（仅站长） */
    void updateAdminCode(Integer operatorRole, String newCode);
}

/**
 * 管理服务实现：审核、硬删除、用户角色、管理员注册密码。
 * 所有方法都先校验操作者角色（纵深防御），再由 Mapper 执行。
 */
@Service
@RequiredArgsConstructor
public class AdminServiceImpl implements AdminService {
    private final StoryFragmentMapper fragmentMapper;
    private final FragmentLikeMapper likeMapper;
    private final UserMapper userMapper;
    private final FragmentService fragmentService;
    private final SystemConfigMapper systemConfigMapper;
    private final PasswordEncoder passwordEncoder;

    /** 管理列表：按状态筛选；匿名碎片也展示真实昵称，方便管理员判断内容归属 */
    @Override
    public PageBean manageList(Integer status, int pageNum, int pageSize) {
        PageHelper.startPage(pageNum, pageSize);
        List<FragmentVO> list = fragmentMapper.selectManagePage(status).stream()
                .map(this::toAdminVO)
                .toList();
        Page<FragmentVO> page = (Page<FragmentVO>) list;
        return new PageBean(page.getTotal(), page.getResult());
    }

    /** 审核通过：只允许把「待审核」变成「已发布」，防止重复/越权审核 */
    @Override
    public void approve(Long fragmentId) {
        StoryFragment f = requireExists(fragmentId);
        if (f.getStatus() != StoryFragment.STATUS_PENDING) {
            throw new BusinessException(ResultCode.FRAGMENT_NOT_PUBLISHED, "只能审核待审核碎片");
        }
        fragmentMapper.updateStatus(fragmentId, StoryFragment.STATUS_PUBLISHED);
    }

    /** 硬删除：删行并清点赞，前端弹窗已提示不可恢复 */
    @Override
    public void deleteFragment(Long fragmentId) {
        requireExists(fragmentId);
        fragmentMapper.deleteById(fragmentId);
        likeMapper.deleteByFragmentAndUser(fragmentId, null);
    }

    /** 用户分页列表（仅站长，由拦截器 + Service 双重校验） */
    @Override
    public PageBean users(int pageNum, int pageSize) {
        PageHelper.startPage(pageNum, pageSize);
        List<User> list = userMapper.selectPage();
        Page<User> page = (Page<User>) list;
        return new PageBean(page.getTotal(), page.getResult());
    }

    /** 指定/撤销管理员：只有站长能操作；站长本人不可被修改（防止权限被锁死） */
    @Override
    public void updateRole(Integer operatorRole, Long targetUserId, Integer role) {
        if (operatorRole == null || operatorRole != User.ROLE_OWNER) {
            throw new BusinessException(ResultCode.FORBIDDEN);
        }
        if (role == null || (role != User.ROLE_USER && role != User.ROLE_ADMIN)) {
            throw new BusinessException(ResultCode.BAD_REQUEST, "角色只能是 0 或 1");
        }
        User target = userMapper.selectById(targetUserId);
        if (target == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "用户不存在");
        }
        if (target.getRole() == User.ROLE_OWNER) {
            throw new BusinessException(ResultCode.CANNOT_MODIFY_OWNER);
        }
        userMapper.updateRole(targetUserId, role);
    }

    @Override
    public void updateAdminCode(Integer operatorRole, String newCode) {
        if (operatorRole == null || operatorRole != User.ROLE_OWNER) {
            throw new BusinessException(ResultCode.FORBIDDEN);
        }
        if (newCode == null || newCode.length() < 6) {
            throw new BusinessException(ResultCode.BAD_REQUEST, "管理员注册密码至少 6 位");
        }
        systemConfigMapper.upsert(SystemConfig.KEY_ADMIN_REGISTER_CODE, passwordEncoder.encode(newCode));
    }

    private StoryFragment requireExists(Long fragmentId) {
        StoryFragment f = fragmentMapper.selectById(fragmentId);
        if (f == null) {
            throw new BusinessException(ResultCode.NOT_FOUND, "碎片不存在");
        }
        return f;
    }

    /** 管理端专用转换：无论是否匿名都显示真实昵称 */
    private FragmentVO toAdminVO(StoryFragment f) {
        FragmentVO vo = fragmentService.toVO(f, false);
        User author = userMapper.selectById(f.getUserId());
        vo.setAuthorName(author == null ? "未知用户" : author.getNickname());
        return vo;
    }
}
```

```java
/**
 * 配置种子数据：应用启动时把默认管理员注册密码写入 system_config。
 * 为什么用 CommandLineRunner：SQL 里写死 BCrypt 哈希不方便维护，启动时从 yml 读取并加密落库更清晰。
 * 只会在键不存在时写入，站长改过的密码不会被覆盖。
 */
@Component
@RequiredArgsConstructor
public class ConfigSeedRunner implements CommandLineRunner {
    private final SystemConfigMapper systemConfigMapper;
    private final PasswordEncoder passwordEncoder;
    /** 默认注册密码来自 application.yml 的 app.admin.default-register-code */
    @Value("${app.admin.default-register-code}")
    private String defaultRegisterCode;

    @Override
    public void run(String... args) {
        // 已有配置（站长改过）就跳过，避免每次启动重置密码
        if (systemConfigMapper.selectByKey(SystemConfig.KEY_ADMIN_REGISTER_CODE) == null) {
            systemConfigMapper.upsert(SystemConfig.KEY_ADMIN_REGISTER_CODE, passwordEncoder.encode(defaultRegisterCode));
        }
    }
}
```

```js
import axios from 'axios'
import { userStore } from '../stores/user'
const request = axios.create({ baseURL: '/api', timeout: 10000 })
request.interceptors.request.use((config) => {
  if (userStore.token) config.headers.Authorization = `Bearer ${userStore.token}`
  return config
})
request.interceptors.response.use(
  (res) => {
    const body = res.data
    if (body.code !== 200) return Promise.reject(new Error(body.message || '请求失败'))
    return body.data
  },
  (err) => {
    if (err.response?.status === 401) {
      userStore.logout()
      if (!location.hash.startsWith('#/login')) location.hash = '#/login'
    }
    const msg = err.response?.data?.message || err.message || '网络错误'
    return Promise.reject(new Error(msg))
  }
)
export default request
```

```vue
<script setup>
import { ref } from 'vue'
import { useRouter } from 'vue-router'
import { login, register, getMe } from '../api/auth'
import { userStore } from '../stores/user'
import CaptchaField from '../components/CaptchaField.vue'

const router = useRouter()
const mode = ref('login')
const form = ref({ username: '', nickname: '', password: '', isAdmin: false, adminCode: '' })
const captcha = ref({ key: '', answer: '' })
const error = ref('')
const submitting = ref(false)

async function submit() {
  error.value = ''
  submitting.value = true
  try {
    let token
    if (mode.value === 'login') {
      token = await login({ username: form.value.username, password: form.value.password })
    } else {
      token = await register({
        username: form.value.username,
        nickname: form.value.nickname,
        password: form.value.password,
        isAdmin: form.value.isAdmin,
        adminCode: form.value.adminCode || null,

        captchaAnswer: captcha.value.answer
      })
    }
    userStore.setLogin(token, null)
    const me = await getMe()
    userStore.setUser(me)
    router.push(me.role >= 1 ? '/admin' : '/')

    error.value = e.message

    submitting.value = false
  }
```
