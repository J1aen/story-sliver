# 腾讯云部署指南（匿名故事碎片墙）

> 目标：`http://服务器公网IP:8080` 直接访问完整网站（前端 + 后端单端口）。

## 0. 准备

- 服务器：腾讯云轻量/CVM，Ubuntu 22.04 或 24.04，已放行 8080 端口（控制台防火墙）
- 本机已打好包：`fragment-story/target/fragment-story-0.0.1-SNAPSHOT.jar`（已含前端页面）
- 防火墙「来源」必须填 **`0.0.0.0/0`**（带 `/0` 才是「所有 IP」，只填 `0.0.0.0` 会被当成单个 IP 而放行无效）

## 1. SSH 登录

```bash
ssh ubuntu@服务器公网IP
# 密码是腾讯云短信/控制台给的初始密码；建议登录后改密码或配置密钥
```

## 2. 安装 JDK 17 与 MySQL 8

```bash
sudo apt update
sudo apt install -y openjdk-17-jre-headless mysql-server
sudo systemctl enable --now mysql
```

## 3. 建库建账号

```bash
sudo mysql
```

```sql
CREATE DATABASE IF NOT EXISTS story_sliver DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'story'@'localhost' IDENTIFIED BY '<数据库密码>';
GRANT ALL PRIVILEGES ON story_sliver.* TO 'story'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

导入表结构（init.sql 里去掉前两行 `CREATE DATABASE`/`USE`，或单独执行那两行）：

```bash
mysql -ustory -p<数据库密码> story_sliver < init.sql
```

## 4. 创建目录并上传 jar

```bash
mkdir -p /home/ubuntu/story/headimage /home/ubuntu/story/backups
```

本机执行（上传 jar）：

```bash
scp fragment-story-0.0.1-SNAPSHOT.jar ubuntu@服务器公网IP:/home/ubuntu/story/
```

## 5. 配置（两种方式任选）

**方式 A（推荐）：改 systemd 环境变量**——编辑 `story.service` 里三行：

```
SPRING_DATASOURCE_USERNAME=数据库账号（生产用 story，不要用 root）
SPRING_DATASOURCE_PASSWORD=数据库密码
APP_UPLOAD_AVATAR_DIR=/home/ubuntu/story/headimage
APP_JWT_SECRET=32位以上随机字符串（可用 openssl rand -hex 32 生成）
```

**方式 B：改 jar 内配置**——解压后修改 `application.properties`，再重新打包上传。

## 6. systemd 常驻

```bash
sudo cp story.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now story
sudo systemctl status story
```

## 7. 防火墙

腾讯云控制台：轻量/CVM 防火墙放行 **TCP 8080**（入站），来源填 **`0.0.0.0/0`**。
SSH 端口 22 同样要放行（默认规则通常已有；来源也要是 `0.0.0.0/0`）。

## 8. 备份（每天凌晨 3 点）

```bash
chmod +x backup.sh
crontab -e
# 添加：0 3 * * * /home/ubuntu/story/backup.sh
```

> 注意：`backup.sh` 在 Windows 上编辑过会带 CRLF 换行，Linux 跑会报 `$'\r': command not found`。
> 上传后先执行一次 `sed -i 's/\r$//' /home/ubuntu/story/backup.sh` 转成 LF，再测试 `bash backup.sh`。

## 9. 验证

```bash
curl http://localhost:8080/api/auth/captcha   # 接口正常
```

浏览器打开 `http://服务器公网IP:8080` → 注册（管理员 + <管理员注册密码>）→ 发布 → 管理后台审核 → 全流程可用。

## 10. 上线后检查清单（安全）

- [ ] JWT 密钥已改为随机长串（≥32 字节）
- [ ] 数据库密码已改强密码
- [ ] 服务器 SSH 改为密钥登录（可选但推荐）
- [ ] 防火墙只放行 8080 与 SSH
- [ ] 备份定时任务已生效（`crontab -l` 确认）
- [ ] 试用到期前已做备份并规划续费/迁移
